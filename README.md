# stevenrbrown.org

Source code for my personal portfolio website — [stevenrbrown.org](https://www.stevenrbrown.org). Built to showcase my background in cybersecurity and AI, my projects, and my path through Penn State's Cybersecurity Analytics and Operations program.

This isn't a template or a tool meant for others to use — it's the actual code behind my live site.

## What's on the site

- **About** - Background, education, and my approach to problem-solving.
- **Projects** - GolfCaddie, CloakAI, Quotework, Finio, and other work, including a SOC setup, network security audit, and various applications.
- **Skills** - Security & compliance, SIEM & monitoring, AI & infrastructure, and general development tooling.
- **Contact** - A working contact form for reaching out about opportunities.
- **Blog** - My take on current events in the tech world from a security mindset.

## Tech stack

- [Next.js](https://nextjs.org) (React framework)
- React
- [Tailwind CSS](https://tailwindcss.com)

## Running it locally

Mostly kept here for my own reference when setting up on a new machine:

```bash
git clone https://github.com/Steven6Brown/portfolioWebsite.git
cd portfolioWebsite
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
